# Arcademic
A retro-inspired educational platform that transforms learning into an arcade experience.
Level Up Your Knowledge.

Arcademic is an open-source educational platform inspired by the golden era of arcade games. It combines gamification, adaptive quizzes, and interactive learning to transform traditional assessments into engaging experiences.

Designed for teachers and students, Arcademic supports multiple subjects through reusable question banks, making it easy to create immersive learning experiences without modifying the core application.

✨ Features (planned)
🕹️ Retro arcade-inspired interface
📚 Multiple subjects through JSON question banks
🎯 EXANI/CENEVAL practice mode
⚡ Arcade mode with lives, combos, and XP
📊 Learning analytics and progress tracking
📱 Responsive design (Desktop, Android, iOS)
🌐 Progressive Web App (PWA)
💾 Offline support
🔓 Open source
